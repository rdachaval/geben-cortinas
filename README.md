# Cortinas a medida · Geben Argentina

Página de cortinas con el formulario para pedir presupuesto. Se publica con GitHub Pages en https://cortinas.gebenargentina.com.

El formulario manda los pedidos a un Apps Script ligado a la planilla "Pedidos de cortinas" (Geben Compartido → Ventas), que escribe una fila por ventana y avisa a ventas@gebenargentina.com. El script y las instrucciones están en el vault: `Projects/Publicidad In-House/landing-cortinas/`.
